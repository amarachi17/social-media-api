# Social Media API (Django REST Framework)

## 📌 Overview  
This is a backend REST API built with Django REST Framework that simulates a simple social media platform.

It allows users to register, authenticate, create posts, and interact with content.

---

## 🚀 Features  
- User registration & authentication  
- JWT authentication (if you used it)  
- Create, update, delete posts  
- Comment system  
- API endpoints for social interactions  

---

## 🛠️ Tech Stack  
- Python  
- Django  
- Django REST Framework  
- SQLite  

---

## 🔐 Authentication  
This API uses token-based authentication to secure endpoints.

---

## 📡 API Endpoints  
- POST /register  
- POST /login  
- GET /posts  
- POST /posts  
- POST /comments  

---

## ▶️ How to Run  
1. Clone the repository  
2. Install dependencies: `pip install -r requirements.txt`  
3. Run migrations: `python manage.py migrate`  
4. Start server: `python manage.py runserver`
